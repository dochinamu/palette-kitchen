# 팔레트키친

1인 가구를 위한 레시피북 서비스 "팔레트키친"의 사전 신청 랜딩 페이지입니다.

- `index.html` 한 파일로 된 정적 페이지예요. 빌드 과정이 없어요.
- 방문·클릭·신청 기록은 Google Apps Script 엔드포인트로 보내요(`index.html` 안 `ENDPOINT`).

## Netlify 배포

GitHub 저장소를 연결하고 Build command는 비워 두고, Publish directory는 `/`(루트)로 두면 돼요.
사이트 주소가 `palette-kitchen.netlify.app`이 아니면 `index.html`의 `og:url`, `og:image` 주소를 실제 주소로 바꿔 주세요.

## 문구 톤 가이드

페이지 구조는 "불편 → 이유 → 해결 → 그 뒤"의 이야기 순서지만, 문구에는 그 설정이 드러나지 않게 써요.

- 비유와 설정 단어를 쓰지 않아요. 범인, 악당, 함정, 갇혀 있다 같은 말 대신 일상에서 쓰는 말로 써요.
- 방문자의 마음이나 행동을 단정하지 않아요. "~하시죠?", "~했다면 ~때문이에요"처럼 짚어 내지 말고, 장면을 보여 주고 공감은 읽는 사람에게 맡겨요.
- 탓하지 않아요. 저장하는 습관이 아니라, 레시피가 흩어지는 상황을 이야기해요.
- 혼잣말, 밈, 과장은 쓰지 않아요. 화면 속 예시는 실제 앱에 나올 법한 정보(제목, 날짜, 출처)로 채워요.
- 해요체로, 짧고 담백하게 써요. 한 문장에 한 가지만 말해요.
- 같은 말을 구역마다 반복하지 않아요. 맨 위, 이유, 마무리 문장이 서로 다른 말을 하게 해요.
- 지킬 수 있는 약속만 써요. 가격, 혜택, 출시일은 정해진 것만 써요.
